À propos — {{ app_name }} {{ version }}

GGR Vacations archive les vacations HF entre le radio-club {{ club_callsign }} et les bateaux de la flotte Golden Globe Race. Le club émet un bulletin météo tous les jours à {{ time_utc }} TU sur {{ tx_mhz }} MHz USB (QRG nominale ± {{ qrg_tolerance_khz }} kHz) et écoute les accusés de réception sur {{ ack1_mhz }} MHz USB et {{ ack2_mhz }} MHz USB (QRG ± {{ qrg_tolerance_khz }} kHz). Tous les jours à {{ buddy_time_utc }} TU, un buddy call est écouté sur {{ '%.0f'|format(buddy_main_khz) }} kHz USB (principale) et {{ '%.0f'|format(buddy_alt_khz) }} kHz USB (secours), depuis plusieurs KiwiSDR choisis pour la propagation (NVIS et saut 1 hop) vers le centroïde des skippers suivis ({{ buddy_skippers_short }}{% if buddy_include_fleet %} + flotte{% endif %}). Le bulletin et les deux ACK sont enregistrés en parallèle pendant toute la vacation (pas d’attente de fin de bulletin). Les QRG se règlent dans Réglages.

Fonctionnement

  • Position moyenne de la flotte via le tracker Yellowbrick GGR 2026.
  • Choix des KiwiSDR : bulletin = proximité flotte (12–17 MHz) ; buddy call = couverture 4483 et 6516 kHz + NVIS / saut 1 hop à 12:00 TU.
  • Screencast de l’interface SDR (waterfall / VFO) muxé avec l’audio USB 12 kHz.
  • WAV des deux QRG d’accusé en parallèle, depuis trois Kiwi : près de la flotte, en France, vers Tahiti.
  • Replay dans cette interface, comme si l’on était devant le récepteur.

Crédits

  • Radio-club F6KUF — émission du bulletin météo.
  • Skippers et organisation Golden Globe Race — tracker Yellowbrick.
  • Opérateurs KiwiSDR — récepteurs HF publics.
  • Liste des récepteurs : rx.linkfanel.net (agrégation kiwisdr.com).
